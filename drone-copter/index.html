Controller Guide

左コントローラー

スティック↑↓ 前進 / 後退
スティック←→ 左旋回 / 右旋回
X ボタン 起動 / 終了シーケンス
Y ボタン サウンド ON/OFF
トリガー 速度ダウン
グリップ ドローンを掴む

右コントローラー

スティック↑↓ 上昇 / 下降
スティック←→ 左移動 / 右移動
スティック押込 HUDモード ON/OFF
A ボタン 衝突判定 ON/OFF
B ボタン 自動帰還モード
トリガー 速度アップ
グリップ ドローンを掴む

ハンドトラッキング対応

コントローラーなしでも操作可能。ピンチジェスチャーでドローンを掴んで移動・スケール変更ができます。

Quest 3 / Quest Pro 対応 | WebXR Immersive Experience

ドローンを表示するには「MRを開始」または「VRを開始」をタップしてください
